Named case groups

Create up to eight color-coded groups (for example, Awaiting documents or Immigration follow-up). Assign a group to any local case, then filter or group the case list. Group names and assignments stay in this browser and are included in Backups.

One group per case. Groups are independent of the case type and visa processing status; deleting a group does not delete student cases.

Letter checkers

These are the names of staff checking the letters, not student data. The same names label the checker columns in Student Lists and the optional top-right review table on visa letters. Add, rename, delete, or reorder the checkers here; changes stay in this browser.

Default letter checkers: หน.บน. | ผศ.ดร.ธรรญธร | อ.เนาวกานต์. The list remains centered on A4 and the wide checker columns may extend past the ordinary text margins. Their cells remain blank for handwritten notes and signatures. The optional letter review box uses the first three checkers.
